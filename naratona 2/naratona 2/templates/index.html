01 — ENTENDENDO

O que são algoritmos de redes sociais?

Um algoritmo é um conjunto de regras e instruções utilizadas por um sistema para realizar determinada tarefa.

Nas redes sociais, algoritmos são utilizados para organizar uma quantidade enorme de conteúdos e decidir quais publicações podem ser mais interessantes para cada usuário.

Imagine que milhões de pessoas publiquem fotos, vídeos, textos e outros conteúdos ao mesmo tempo. Seria impossível mostrar tudo para uma única pessoa.

Por isso, os sistemas analisam vários sinais para tentar organizar o feed de maneira personalizada.

02 — PROCESSO

Como o algoritmo funciona?

01

Coleta de sinais

O sistema observa ações realizadas pelo usuário, como curtidas, comentários, pesquisas e visualizações.

02

Análise

Os dados são analisados para identificar padrões e possíveis interesses.

03

Classificação

Os conteúdos podem receber diferentes níveis de prioridade dentro do sistema.

04

Recomendação

O sistema organiza os conteúdos que poderão aparecer para aquele usuário.

03 — SINAIS

O que pode influenciar uma recomendação?

❤️

Curtidas

Uma curtida pode representar que o usuário teve algum nível de interesse naquele conteúdo.

💬

Comentários

Comentários representam uma interação mais ativa com a publicação.

↗️

Compartilhamentos

Compartilhar um conteúdo demonstra que ele foi considerado interessante o suficiente para ser enviado para outra pessoa.

⏱️

Tempo de visualização

O tempo que alguém passa observando um conteúdo pode ser um dos sinais utilizados por sistemas de recomendação.

🔎

Pesquisas

Pesquisas podem ajudar o sistema a identificar assuntos que despertam curiosidade no usuário.

👥

Relacionamentos

Interações frequentes com determinadas pessoas ou contas também podem influenciar a organização do conteúdo.

⚠️ Importante

Este mini game é uma simulação educativa. Os pesos utilizados aqui são inventados para demonstrar a lógica de um sistema de recomendação.

Redes sociais reais utilizam sistemas muito mais complexos e diferentes plataformas podem utilizar sinais e modelos diferentes.

07 — CONCLUSÃO

O algoritmo tenta organizar uma quantidade enorme de informações.

Em vez de simplesmente mostrar todas as publicações existentes, sistemas de recomendação utilizam sinais para ajudar a decidir quais conteúdos podem ser apresentados para cada usuário.

O mais importante é entender que não existe necessariamente um único "algoritmo das redes sociais". Cada plataforma pode possuir sistemas, objetivos e métodos diferentes.
